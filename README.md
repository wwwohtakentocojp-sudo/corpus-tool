# コーパス分析ツール（統計リテラシー不要・言語学者向け）

## ★ データの取り扱いについて（最初にお読みください）

- **読み込んだテキストは、外部に一切送信されません。** すべての処理はあなたのパソコンの中だけで行われます。
  ブラウザで開きますが、通信相手は自分のパソコン（localhost）だけです。
- AI による解説文の生成（任意機能・APIキーが必要）を使う場合でも、
  **API に送られるのは「分析結果の数値とフラグ（警告の種類）」だけ**です。
  原文・用例・語そのもの・固有名詞は送られません。語は `{WORD}` のような目印に置き換えて送り、
  返ってきた文章にツール側で語を戻します。
- APIキーが無くても、すべての分析機能と警告表示は動作します。
- Streamlit（画面を作る仕組み）の利用統計送信も無効にしてあります。

著作権のあるデータ（BCCWJ、DeReKo 等の再配布禁止コーパス、未公開のインタビュー記録など）を
安心して分析できるよう、この方針を守って開発しています。

## 起動方法（Python の知識は不要です）

### Windows

1. このフォルダの `start.bat` をダブルクリックします。
2. 初回だけ、必要な部品（Python 本体と分析ライブラリ）を自動でダウンロードします。数分かかります。
   「Windows によって PC が保護されました」と出た場合は「詳細情報」→「実行」を押してください。
3. ブラウザが自動で開き、ツールの画面が表示されます。開かない場合は、ブラウザで `http://localhost:8501` を開いてください。
4. 終了するときは、黒いウィンドウを閉じてください。

### macOS / Linux

ターミナルでこのフォルダに移動し、次を実行します。

```bash
bash start.sh
```

## 使い方（現在の段階）

1. **データを読み込む** … .txt ファイルを複数選んで読み込みます。文字コードは自動判定します。
   青空文庫のファイルは、ルビや注記を自動で取り除けます。
2. **前処理の設定** … 語のまとめ方（活用形をまとめるか、表記ゆれをまとめるか）を選びます。
3. **基本統計** … 延べ語数・異なり語数・語彙の豊かさ（TTR / 標準化TTR）・品詞の構成比。
4. **頻度分析** … 出現回数・100万語あたりの回数（pmw）・散らばり具合（分散度DP）。
   一部の文書に偏っている語には警告を出し、どの文書に出ているかを確認できます。
5. **用例検索（KWIC）** … 語の前後の文脈を一覧し、前後の語で並べ替え、CSV に保存できます。

どの画面でも、数字の横の「?」や「この画面の数字の読み方」を開くと、
その数字が何を意味し、どこまで主張してよく、何を主張してはいけないかを確認できます。

図を PNG で保存するには、図の右上に出るカメラのアイコンを押してください（ブラウザの機能で保存されます）。

同じ形で意味の違う語（「ライト（光）」と「ライト（軽い）」など）は別の語として数えます。
画面には「ライト」とだけ出るため2行に分かれて見えますが、
頻度分析画面の「集計キーを表示」を ON にすると区別の内訳を確認できます。

## サンプルデータ

```bash
uv run python scripts/download_samples.py
```

`samples/ja/` に青空文庫の作品（夏目漱石『こころ』『坊っちゃん』、芥川龍之介『羅生門』）が保存されます。

## 設定の変更

`config.yaml` に、警告を出す基準（たとえば「総語数が1万語未満なら警告」）がまとめてあります。
これらは分野で広く使われる目安であって絶対的な基準ではありません。変更したときは論文にその値を明記してください。

## 開発者向け

```bash
uv sync
uv run pytest
uv run streamlit run app.py
```

構成:

- `analyzers/` … 言語ごとの処理。言語固有の知識はここに閉じ込める（`base.py` が共通インターフェース）
- `corpus/` … 読み込み・整形・データモデル・分析設定
- `stats/` … 統計計算（純粋関数。Streamlit に依存しない）
- `interpretations/` … 解説システム。`glossary.yaml`（第1層・固定テキスト）、`rules.py`（第2層・判定ルール）、
  `narrator.py`（第3層・文章化、後続フェーズ）
- `views/` … 画面
- `tests/` … 手計算値と照合する単体テスト
