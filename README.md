# コーパス分析ツール（統計リテラシー不要・言語学者向け）

統計の知識がない言語学研究者が、自分で集めたテキストを自力で分析できるようにするツールです。
数値を出して終わりにせず、その数値が何を意味し、どこまで主張してよく、何を主張してはいけないかを、
統計用語を使わない日本語で必ず併記します。対応言語は日本語・英語・ドイツ語です。

使い方は2通りあります。**ご自身のデータを分析する場合は、必ずローカル版を使ってください。**

| | 試してみる（デモ版） | 自分のデータで使う（ローカル版） |
|---|---|---|
| 場所 | ブラウザで開く（Streamlit Community Cloud） | 自分のパソコン |
| データ | 同梱サンプルのみ | 自分のファイル |
| 外部送信 | アップロードしたファイルはサーバーを経由する | **一切行わない** |
| 導入 | 不要 | `start.bat` をダブルクリック |

## 試してみる（デモ版）

デモ版: **https://＜デプロイ後に URL を記入＞**

同梱サンプル（青空文庫の日本語作品、Project Gutenberg の英語作品、Leipzig Corpora Collection のドイツ語ニュース文。
出典とライセンスは `samples/README.md`）で、読み込みから基本統計・頻度分析・KWIC・コロケーション・特徴語抽出までの
全機能を体験できます。
各画面で表の行を選ぶと「この語の読み方」が表示され、論文にそのまま書ける文例と、言ってはいけないことが確認できます。

**★ デモ版に、ご自身の資料をアップロードしないでください。**
デモ版はアップロードしたファイルがサーバーを経由します。未公開のインタビュー記録、再配布が禁止されている
コーパス（BCCWJ、DeReKo など）、著作権のある資料は、デモ版に入れないでください。
ご自身のデータの分析は、下の「ローカル版」で行ってください。

デモ版の制限:
- アップロードは 1 ファイル 5 MB まで
- ドイツ語の解析は小さい言語モデル（de_core_news_sm）のみ。精度重視のモデル（lg）は使えません
- 同時に多くの人が使うと遅くなることがあります

## 自分のデータで使う（ローカル版）

### ★ データの取り扱いについて

- **ローカル版は、一切の外部送信を行いません。** 読み込んだテキストも、分析結果も、あなたのパソコンの外には出ません。
  ブラウザで開きますが、通信相手は自分のパソコン（localhost）だけです。
- 解説文は AI ではなく、ツールに組み込まれた固定の文言と判定ルールから組み立てます。
  そのため同じ数値には必ず同じ警告が出ます。インターネット接続も API キーも不要です。
- Streamlit（画面を作る仕組み）の利用統計送信も無効にしてあります。
- 例外は、初回起動時の部品のダウンロードと、サンプルデータの取得スクリプトだけです
  （どちらもあなたのデータを送るものではありません）。

著作権のあるデータや未公開の資料を安心して分析できるよう、この方針を守って開発しています。

### 導入（Python の知識は不要です）

**Windows**

1. このリポジトリを ZIP でダウンロードして展開するか、`git clone` します。
2. フォルダの中の `start.bat` をダブルクリックします。
3. 初回だけ、必要な部品（Python 本体と分析ライブラリ）を自動でダウンロードします。数分かかります。
   「Windows によって PC が保護されました」と出た場合は「詳細情報」→「実行」を押してください。
4. ブラウザが自動で開き、ツールの画面が表示されます。開かない場合は `http://localhost:8501` を開いてください。
5. 終了するときは、黒いウィンドウを閉じてください。

**macOS / Linux**

ターミナルでフォルダに移動し、次を実行します。

```bash
bash start.sh
```

### 使い方

1. **データを読み込む** … 3通りの入力に対応しています。
   - .txt ファイル（複数選択・zip・フォルダのパス）。文字コードは自動判定。青空文庫の注記は自動で除去できます。
   - CSV / Excel（1行 = 1文書）。本文の列と、グループ列（年・ジャンル・話者など）を選びます。
   - サンプルデータ（同梱の `samples/demo/`。完全版は `scripts/download_samples.py` で取得）。
   読み込み後に、データ量の不足やグループ間の文書数の偏りを分析前に警告します。
2. **前処理の設定** … 語のまとめ方（活用形をまとめるか、表記ゆれをまとめるか）を選びます。
3. **基本統計** … 延べ語数・異なり語数・語彙の豊かさ（TTR / 標準化TTR）・品詞の構成比。
4. **頻度分析** … 出現回数・100万語あたりの回数（pmw）・散らばり具合（分散度DP）。
5. **用例検索（KWIC）** … 語の前後の文脈を一覧し、前後の語で並べ替え、CSV に保存できます。
   共起語やグループで絞り込めます（コロケーション・特徴語の画面から、該当する用例だけを開けます）。
6. **コロケーション** … 共起頻度・MI・Tスコア・logDice・G² を同時に算出。表は logDice の高い順です。
   共起の範囲は「同一文内」「前後 n 語」「係り受け」の3方式で、言語ごとの既定と理由を画面に表示します。
7. **特徴語（2群比較）** … グループ列の2つの値を比べ、G²（差があるか）と log ratio（どれくらい違うか）を併記します。

どの画面でも、数字の横の「?」や「この画面の数字の読み方」を開くと、その数字の意味と注意を確認できます。
表の行を選ぶと「この語の読み方」が出ます。構成は【この数字が言っていること】【論文に書くなら】
【言ってはいけないこと】【次に確認すべきこと】で、後ろ2つは注意すべき状況のときだけ現れます。

図を PNG で保存するには、図の右上に出るカメラのアイコンを押してください。

### 対応言語と言語ごとの処理

日本語（UniDic 短単位）、英語（spaCy）、ドイツ語（spaCy + HanTa + 複合語分割）。
言語は読み込み画面で選びます。自動判定は初期値の提案だけで、最終的な選択は利用者が行います。

ドイツ語では次の処理を設定画面で切り替えられます（既定値はすべて「数値を壊さない安全側」です）:

- 分離動詞の再結合（rufe … an → anrufen）: 既定 ON
- 複合語の分割（Autobahnraststätte → Autobahn + Raststätte）: 既定 OFF。ON にすると「元の語」と「構成要素」の両方を集計表示
- 大文字と小文字の区別: 既定「区別する」（Essen と essen を統合しない）
- 見出し語化: spaCy / HanTa / 両方を比較
- 正書法の統一（1996年改革、ß→ss、ウムラウト）: 既定 OFF。新旧表記の混在を検出したときだけ提案します

同じ形で意味の違う語（「ライト（光）」と「ライト（軽い）」など）は別の語として数えます。
画面には「ライト」とだけ出るため2行に分かれて見えますが、頻度分析画面の「集計キーを表示」を ON にすると区別の内訳を確認できます。

精度重視の大きな言語モデル（英語・ドイツ語、1言語あたり数百MB）が必要な場合:

```bash
uv sync --extra large-models
```

### サンプルデータ

```bash
uv run python scripts/download_samples.py
```

`samples/ja/` に青空文庫の作品、`samples/en/` に Project Gutenberg の作品、
`samples/de/` に Leipzig Corpora Collection のニュース文と頻度リストが保存されます。
Leipzig の頻度リストは、本ツールの頻度集計が桁として妥当かを確かめるための基準データです:

```bash
uv run python scripts/check_leipzig.py
```

### 設定の変更

`config.yaml` に、警告を出す基準（たとえば「総語数が1万語未満なら警告」）がまとめてあります。
これらは分野で広く使われる目安であって絶対的な基準ではありません。変更したときは論文にその値を明記してください。

## 解説文の仕組み

解説は3つの部品から組み立てます。AI は使いません。

1. 用語辞書（`interpretations/glossary.yaml`）… 各指標の意味と注意。画面の「?」から参照します。
   本文中の閾値は `{変数名}` で書かれ、`config.yaml` の値で埋められます（数値を二重に持たないため）。
2. 判定ルール（`interpretations/rules.py`）… 数値と閾値から「注意すべき状況（フラグ）」を決めます。
   辞書とルールの対応表は `docs/consistency.md` にあります。
3. 解説文（`interpretations/explainer.py`）… 立っているフラグに対応する文だけを並べます。
   フラグが無ければ注意は表示しません。毎回同じ注意が並ぶと読まれなくなるためです。

出力サンプルは次で確認できます:

```bash
uv run python scripts/explain_samples.py
```

## 開発者向け

```bash
uv sync
uv run pytest
uv run streamlit run app.py --server.address localhost
```

構成:

- `analyzers/` … 言語ごとの処理。言語固有の知識はここに閉じ込める（`base.py` が共通インターフェース）
- `corpus/` … 読み込み・整形・データモデル・分析設定
- `stats/` … 統計計算（純粋関数。Streamlit に依存しない）
- `interpretations/` … 解説システム（用語辞書・判定ルール・解説文の組み立て）
- `ui/` … 画面の共通部品。`demo.py` が公開デモ版の切り替え
- `views/` … 画面
- `tests/` … 手計算値と照合する単体テスト

### 公開デモ版（Streamlit Community Cloud）の構成

- 依存関係は `requirements.txt` で導入されます（Community Cloud は uv ではなく pip を使うため）。
  `pyproject.toml` / `uv.lock` を変更したら、次のコマンドで `requirements.txt` を作り直してください。
  手で編集しないでください。

  ```bash
  uv export --no-dev --no-hashes --no-emit-project --format requirements-txt -o requirements.txt
  ```

  開発用（pytest）と大モデル（`large-models`）は含まれません。spaCy モデルは sm のみです。
- OS パッケージは不要なので `packages.txt` はありません。
- Python は 3.11 を選んでください（`.python-version` と同じ）。
- デモ版の挙動は環境変数（Community Cloud では Secrets）で切り替えます。ローカル版では設定不要です。

  | 変数 | 意味 | 既定 |
  |---|---|---|
  | `DEMO_MODE` | `true` でデモ版（バナー表示、アップロード上限、sm モデル固定、サンプル自動取得） | `false` |
  | `DEMO_MAX_UPLOAD_MB` | デモ版のアップロード上限（MB） | `5` |
  | `REPO_URL` | サイドバーに出す GitHub リポジトリの URL | プレースホルダ |

- デモ用サンプルは加工済みで `samples/demo/` に同梱しています（すべて著作権切れまたは CC ライセンス。出典は `samples/README.md`）。
  デモ版は外部からの取得を行いません。更新するときは `scripts/download_samples.py` → `scripts/make_demo_samples.py` の順に実行します。
- 公開の手順（履歴の author 書き換えとバックアップ、push、Community Cloud の設定）は `docs/deploy.md` にあります。
